# Брэдфорд — сайт студии красоты

Многостраничный статический сайт для студии красоты «Брэдфорд» (Минск, ул. Гурского, 45). Чистый HTML, CSS и JavaScript: без сборки, фреймворков и зависимостей.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: рейтинг, группы услуг, атмосфера салона, галерея |
| `services.html` | Услуги и цены |
| `about.html` | О салоне |
| `contacts.html` | Адрес, телефон, соцсети, карта, форма записи в WhatsApp |

## Структура

```
.
├── index.html
├── services.html
├── about.html
├── contacts.html
├── style.css              # все стили и цвета сайта
├── main.js                # меню, форма записи, плавное появление
├── favicon.ico
├── favicon-32.png
├── favicon-192.png
├── apple-touch-icon.png
└── images/                # фото салона
```

## Возможности

- Адаптивная вёрстка, удобно с телефона
- Мобильное меню
- Плавное появление блоков при прокрутке (отключается у тех, кто выбрал «уменьшить движение»)
- Форма записи: открывает WhatsApp с готовым сообщением
- Карта Яндекса на странице контактов
- Favicon и иконка для экрана iPhone

## Запуск локально

Сборка не нужна. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт открывается по адресу http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое папки (файлы должны лежать в корне, рядом с `index.html`).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту-две сайт появится по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Все пути в проекте относительные, поэтому сайт работает и из подпапки репозитория.

## Что где править

- **Цены и услуги** — `services.html`. Сейчас цена указана только у маникюра френч (75 Br), у остальных стоит «цену уточняйте». Чтобы вписать цену, замените блок `<span class="pr ask">цену уточняйте</span>` на `<span class="pr">80 Br</span>`.
- **Телефон и мессенджеры** — номер указан в футере каждой страницы, в `contacts.html` и в `main.js` (ссылка `wa.me/...` для формы записи). Меняйте во всех местах.
- **Время работы** — `contacts.html`, строка «Время работы».
- **Фото** — папка `images/`. Чтобы заменить фото, положите новое с тем же именем.
- **Цвета** — переменные в начале `style.css`:

```css
:root{
  --rose:#ead9d6;    /* фон героя и акцентные блоки */
  --ivory:#fbf8f6;   /* основной фон */
  --plum:#2b1822;    /* тёмный цвет, кнопки, футер */
  --magenta:#a3175f; /* акцент */
}
```

- **Шрифты** — Cormorant Garamond (заголовки) и Jost (текст), подключаются с Google Fonts.
- **Скорость появления блоков** — класс `.reveal` в конце `style.css`.
